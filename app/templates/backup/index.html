Backup pela linha de comando (cron)

Os mesmos dados podem ser exportados/restaurados por CLI — útil para agendar no homelab: 

# backup completo da instância
docker compose exec todonow flask --app wsgi backup --scope full

# backup de um usuário específico
docker compose exec todonow flask --app wsgi backup --scope user --username meuusuario

# restaurar (mesclar) um arquivo já copiado para o container
docker compose exec todonow flask --app wsgi restore /data/backups/arquivo.json --mode merge

# conferir snapshots existentes
docker compose exec todonow flask --app wsgi snapshots

O banco SQLite fica no volume Docker (/data/todonow.db): parar o container e copiar a pasta /data também é um backup válido.
